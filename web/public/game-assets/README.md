# 演武卡面素材

本目录中的卡面来自玩家社区 **sgmdtx.com**。来源站点、武将与战法目录及下载
日期以 `manifest.json` 的 `source` 区块为唯一结构化记录；原图 CDN 路径格式为
`https://cdn.sgmdtx.com/img/<avatar>.png?v=v3.1.3`。

素材保存为本地静态资源，仅用于本仓库的个人演武选牌与配队界面。此次使用基于
用户对该玩家社区素材的明确许可；没有复制游戏整张背景截图，也不会在运行时
请求社区站点或 CDN。

`manifest.json` 是运行时唯一的名称映射，明确记录中文名、本地路径、品质和
资源类型。武将目录中的「祝融夫人」按本地数据库名称映射为「祝融」，本地文件
仍为 `heroes/zhu_rong_fu_ren.png`。清单覆盖数据库中的全部可用武将和可抽取普通
战法；签名战法与 shadow 战法不作为普通演武抽取卡面收录。覆盖范围和本地文件
由 [`gameAssetsManifest.test.ts`](../../src/gameAssetsManifest.test.ts) 检查，避免清单随数据库更新而漂移。

图片版权及相关权利归原权利人所有。本目录素材不得被理解为本项目对其进行再
授权。界面会为无法解析或加载失败的卡面显示本地文字回退。
