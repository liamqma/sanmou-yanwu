# 演武卡面素材

本目录中的卡面保存为本地静态资源，仅用于本仓库的个人演武选牌与配队界面。
没有复制游戏整张背景截图，运行时也不会请求外部图片服务。

`manifest.json` 是 Web 卡面运行时的权威名称映射，明确记录中文名、本地路径、
品质和资源类型。武将目录中的「祝融夫人」按本地数据库名称映射为「祝融」，
本地文件仍为 `heroes/zhu_rong_fu_ren.png`。清单覆盖数据库中的全部可用武将和
可抽取普通战法；签名战法与 shadow 战法不作为普通演武抽取卡面收录。覆盖范围
和本地文件由
[`gameAssetsManifest.test.ts`](../../src/gameAssetsManifest.test.ts)
检查，避免清单随数据库更新而漂移。

图片版权及相关权利归原权利人所有。本目录素材不得被理解为本项目对其进行再
授权。界面会为无法解析或加载失败的卡面显示本地文字回退。
