# 演武本地素材

本目录中的卡面、回退图，以及 `/daily-yanwu` 专用卡背和环境背景均保存为本地静态
资源，仅用于本仓库的个人演武界面。`daily-yanwu/yanwu-drum-arena-background.png`
是根据 Pi 编写的项目专用视觉简报生成的 1672×941 环境图，构图为巨鼓、背向武者、
木制擂台和右侧暗部；图内没有内嵌文字、卡框、按钮或其他 UI。每天演武运行时直接
使用这张本地高分辨率背景，不再放大、模糊「战八方」卡面，也不会请求外部图片服务。

`manifest.json` 是 Web 武将和战法卡面的权威名称映射，明确记录中文名、本地路径、
品质和资源类型。`daily-yanwu/` 中的卡背 SVG 和环境背景 PNG 是入口专用界面素材，
不属于可抽取卡面清单。武将目录中的「祝融夫人」按本地数据库名称映射为「祝融」，
本地文件仍为 `heroes/zhu_rong_fu_ren.png`。清单覆盖数据库中的全部可用武将和
可抽取普通战法；签名战法与 shadow 战法不作为普通演武抽取卡面收录。覆盖范围
和本地文件由
[`gameAssetsManifest.test.ts`](../../src/gameAssetsManifest.test.ts)
检查，避免清单随数据库更新而漂移。

图片版权及相关权利归原权利人所有。本目录素材不得被理解为本项目对其进行再
授权。界面会为无法解析或加载失败的卡面显示本地文字回退。
