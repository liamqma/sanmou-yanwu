# 演武卡面素材

本目录中的卡面来自玩家社区 **sgmdtx.com**：

- 武将目录：<https://www.sgmdtx.com/wujiang/>
- 战法目录：<https://www.sgmdtx.com/zhanfa/>
- 原图 CDN：`https://cdn.sgmdtx.com/img/<avatar>.png?v=v3.1.3`

素材于 **2026-08-30** 下载并保存为本地静态资源，仅用于本仓库的个人演武
选牌与配队界面。此次使用基于用户对该玩家社区素材的明确许可；没有复制游戏
整张背景截图，也不会在运行时请求社区站点或 CDN。

`manifest.json` 是运行时唯一的名称映射，明确记录中文名、本地路径、品质和
资源类型。武将目录中的「祝融夫人」按本地数据库名称映射为「祝融」，本地文件
仍为 `heroes/zhu_rong_fu_ren.png`。当前收录 100 张武将卡面和 129 张可抽取普通
战法卡面；签名战法与 shadow 战法不作为普通演武抽取卡面收录。

图片版权及相关权利归原权利人所有。本目录素材不得被理解为本项目对其进行再
授权。界面会为无法解析或加载失败的卡面显示本地文字回退。
